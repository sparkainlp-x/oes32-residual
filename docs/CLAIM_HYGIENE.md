# Claim Hygiene — Spark AI NLP (OES / quantum-adjacent)

**Purpose:** Every public sentence about OES or quantum-adjacent work must be inspectable and fail-closed. Disability-led dignity means we refuse stolen physics and stolen medicine.

## Required first paragraph (public OES text)

OES-32/512 is a classical block-syndrome residual latch (16 tiles of 32 when using the 512 path). An optional amplitude map may produce a 5- or 9-qubit *feature* state. It is not a stabilizer code, not a 32- or 512-qubit machine, and not the commercial holographic-installation product.

| Tag | Meaning |

## Forbidden phrases (CI should fail the PR)

- opened a qubit / ran a QPU / executed on quantum hardware (unless named machine + job ID + date)
- gate open as a physical quantum gate
- 32-qubit or 512-qubit Hilbert space as the product
- surface code / HaPPY / [[9,k,d]] as implemented by OES
- 16 independent stabilizers on 9 qubits
- HoloHeal as treatment or medical device
- NASA / Thales / Kognitiv / BIS certified (unless founder supplies a real document)
- 94.92% / FAR=0 / AXI nanoseconds as measured board fact
- Investor Edition framing for simulation metrics
- Production ZCU111 deployment without bitstream hash + timing report
